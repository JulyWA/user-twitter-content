# KOL 投研逻辑沉淀

更新时间：2026-05-14

这份文档不是原文摘录，而是从已筛选知识记录中进一步抽象出的“可复用投研逻辑”。目标是回答：这个 KOL 看项目时到底重视什么信号，什么情况会否决，什么场景下他的判断最有参考价值。

## 一句话总览

| KOL | 核心视角 | 最有价值的场景 | 最重要的信号 |
|---|---|---|---|
| BTCdayu | 价值投资 / 产业链利润池 | AI 基建、稳定币、Pre-IPO、美股、长期 crypto 基础设施 | 真实收入、长期趋势、护城河、估值、管理层、PVP 风险 |
| 0xSunNFT | 链上交易 / 事件驱动 | Meme、CEX 上币、链上新叙事、空投/撸毛、短中期交易 | 龙头地位、催化、流动性、FDV/解锁、方向性、波动性 |

## 0xSunNFT：Meme / 链上交易体系

### 核心判断模型

0xSunNFT 看 Meme 和链上项目，不是单纯看“热不热”，而是看：

1. 是否是本轮叙事里的龙头或龙二。
2. 是否有明确催化，让资金愿意在短期内集中进场。
3. 是否有足够流动性和交易空间，不是一开盘就被 FDV、税、解锁或做市结构卡死。
4. 是否处于周期早中段，而不是已经被广泛讨论后的尾部。
5. 是否有退出路径：CEX、下一轮事件、生态资金轮动、持续注意力。

### 对他来说重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 龙头 / 龙二 | Meme 和链上赛道里，资金最容易集中到少数标的；非龙头大多只是跟涨。 | 先问：它是不是该生态/该叙事里最强的 1-2 个标的？不是则大幅降权。 |
| 真实催化 | 上币、新闻、规则变化、生态轮动、空投、TGE 都可能短期改变供需。 | 只在催化能带来明确方向和波动时参与。 |
| 方向性 + 波动性 | 他对新闻交易的核心定义：利润来自方向性和波动性。 | 事件如果只有热度但方向不清，不能直接视为机会。 |
| CEX 路径 | 上币可以带来流动性和接盘，但也可能压缩利润空间。 | 看是“上币预期带来的机会”，还是“上币后高 FDV 接盘”。 |
| FDV / 流通 / 解锁 | 高 FDV、低流通、持续解锁会导致散户利润空间被压缩。 | TGE 和上币项目必须先看流通盘、解锁条款和做市结构。 |
| 流动性和池子设计 | 链上开盘时，池子范围、初始税、LP、做市决定交易体验。 | 交易前看池子、税率、可成交深度，而不是只看叙事。 |
| 生态轮动 | SOL、TRON、ETH、Hyperliquid 等生态资金会轮动。 | 判断机会时要看资金当前在哪条链、哪个叙事。 |
| KOL / 项目方持续驱动力 | Meme 不只靠第一波热度，还要看后续是否有人持续推动。 | 没有后续驱动力的跟涨标的，涨几倍后反而是做空/避开的对象。 |
| 空投规则和预期 EV | 撸毛不是“有空投就做”，而是看规则、积分、资金占用、时间成本。 | 计算机会成本，优先做赛道最后大毛或规则优势明显的项目。 |

### 否决信号

| 否决信号 | 说明 |
|---|---|
| 非龙头且只是跟涨 | 底部反弹几倍不代表强，可能只是板块 Beta。 |
| 高 FDV + 低流通 + 开盘过热 | CEX/项目方/早期筹码利润空间大，散户容易接最后一棒。 |
| 解锁条款差 | TGE 后一两年额度很快解完，KOL 轮和散户都可能被夹在中间。 |
| 规则反复修改 | 空投、质押、签到、投票规则出尔反尔，说明项目方激励不稳定。 |
| 明牌出货 / 信息不对称 | 庄家、项目方、名人背书后甩锅，普通人没有优势。 |
| 流动性不足 | 开盘后很快到高点，后续没有承接，格局和抄底都危险。 |
| 大所上币后利润被压缩 | 上币不一定是利好，如果筹码、FDV、开盘价已经透支预期。 |

### Meme 周期判断

0xSunNFT 对 Meme 周期的可复用判断：

1. **早期**：新生态、新协议、新叙事出现，龙头还没完全共识化，流动性和注意力刚开始聚集。
2. **主升**：龙头确认，生态资金涌入，CEX/大 KOL/新闻事件放大传播。
3. **扩散**：龙头涨幅过大，资金寻找二线标的，跟涨品种开始爆发。
4. **尾部**：非龙头普涨、项目方坐地起价、估值抬高、上币利润空间被压缩。
5. **退潮**：高 FDV、解锁、流动性不足、叙事疲劳导致大幅回撤。

他的关键倾向是：**宁愿错过尾部跟涨，也要优先参与龙头和明确催化。**

### 适用场景

适合参考：

- Meme 是否值得参与。
- 链上新项目开盘/TGE 是否有交易机会。
- CEX 上币是机会还是接盘。
- 空投/积分项目是否值得投入。
- 新闻事件是否有短线交易价值。

不适合单独参考：

- 长期价值投资。
- 低流动性但有长期基本面的项目。
- 非链上、非事件驱动的传统股权资产。

## BTCdayu：价值投资 / 项目质量体系

### 核心判断模型

BTCdayu 更关心一个项目长期是否“真能赚钱”，而不是短期热度。他的判断一般围绕：

1. 是否处于长期产业趋势。
2. 是否有真实收入和清晰商业模式。
3. 是否处在价值链利润池里。
4. 是否有护城河和管理层质量。
5. 当前估值是否已经透支未来。
6. 是否存在币圈常见的 PVP / 解锁 / VC / 项目方收割结构。

### 对他来说重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 真实收入 | 价值投资的基础，不靠纯情绪支撑。 | 优先看协议收入、公司营收、现金流，而不是 TVL 或交互量。 |
| 长期趋势 | AI、稳定币、算力、存储、光互联等长期趋势能支撑复利。 | 判断项目是不是吃到 3-10 年级别趋势。 |
| 利润池位置 | 最热的叙事不一定最赚钱，真正赚钱的可能是上游/下游环节。 | 研究产业链，找到价值捕获最多的一层。 |
| 护城河 | 牌照、网络效应、品牌、数据、管理层会决定长期质量。 | 把“热度”降权，把“不可替代性”升权。 |
| 估值 / 解禁节奏 | 好资产也可能因为估值和解锁成为坏买点。 | 关注开盘、解禁、流通盘、情绪高点后的回调。 |
| 管理层 / 创始人 | 他很重视“投人”和团队长期主义。 | 看团队是否有真实建设能力，而不是只会发币。 |
| 现金和仓位 | 坏日子不会提前通知，现金是长期生存能力。 | 对高波动资产保持小仓位、留现金。 |

### 否决信号

| 否决信号 | 说明 |
|---|---|
| 项目方最大目标是卖币 | 这是他对大量 crypto 项目的默认警惕。 |
| VC、项目方、交易所共同构成 PVP | 每一层都在找退出流动性，散户胜率下降。 |
| 没有真实收入 | 纯叙事、纯补贴、纯刷数据难以长期持有。 |
| 高估值 + 小流通 | 开盘涨幅诱人，但后续解禁和筹码释放可能持续压制。 |
| 假 TVL / 假交互 | 激励刷出来的数据不能证明真实需求。 |
| 只靠喊单和阴谋的 Meme | 文化和共识不足，只剩 PVP。 |
| 买点过热 | 即使是好资产，如果大众还不知道风险、筹码稀缺、情绪极高，也可能只是短期最肥美但不可追的阶段。 |

### 长期资产判断

BTCdayu 体系下，一个项目更值得研究，通常要满足：

1. 处于大趋势：AI、稳定币、交易基础设施、预测市场、真实基础设施。
2. 有可验证需求：收入、交易量、用户、留存、机构采用。
3. 有价值捕获：不是只提供热闹，而是真能收钱。
4. 有护城河：牌照、规模、品牌、网络效应或管理层。
5. 估值没有完全透支：至少有回调/解禁后的二次机会。

### Meme 判断

他并不完全排斥 Meme，但更谨慎。他看 Meme 的重点不是短期涨幅，而是：

- 是否有文化和共识，而不是喊单与阴谋。
- 是否足够“洗干净”，没有明显控盘和项目方收割。
- 是否能小仓位、长期拿，而不是重仓赌博。
- 是否从 PVP 转向真正的社区文化。

如果一个 Meme 不能拿 6 个月，往往说明买多了或信仰不足。

### 适用场景

适合参考：

- AI 基建项目研究。
- 稳定币 / Circle / 支付基础设施。
- HYPE / Hyperliquid 这类有真实交易收入的 crypto 基础设施。
- Pre-IPO、港股、美股、产业链项目。
- 判断一个项目是否值得长期持有。

不适合单独参考：

- 纯短线链上交易。
- 只有几小时窗口的新闻交易。
- 高频 Meme 冲刺。

## 双体系怎么一起用

对一个新项目，可以这样用：

| 问题 | 用 BTCdayu 视角 | 用 0xSunNFT 视角 |
|---|---|---|
| 这个东西长期值钱吗？ | 看收入、护城河、趋势、估值 | 通常不是主视角 |
| 现在能不能交易？ | 看是否过热、是否有坏买点 | 看催化、流动性、方向性、波动性 |
| 是不是龙头？ | 看长期竞争格局 | 看叙事内龙头/龙二地位 |
| 最大风险是什么？ | PVP、解锁、无收入、估值过高 | FDV、流动性、跟涨、规则变动、明牌出货 |
| 适合什么动作？ | 长持、等回调、建仓、放弃 | 抢催化、短中期交易、撸毛、避开接盘 |

最有价值的地方不是让两个体系给出同一个答案，而是看它们的分歧：

- BTCdayu 看好、0xSun 不看好：可能是好资产但短期不好交易。
- 0xSun 看好、BTCdayu 不看好：可能是好机会但不是长期资产。
- 两者都看好：值得重点研究。
- 两者都否决：大概率不要浪费时间。
