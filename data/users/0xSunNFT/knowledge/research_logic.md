# 0xSunNFT 投研逻辑沉淀

## 核心定位

0xSunNFT 的价值不在于“推荐了哪些币”，而在于他提供了一套链上交易员视角：

- 怎么判断一个 Meme 是否处在正确周期。
- 怎么判断一个事件是否有交易价值。
- 怎么看 CEX 上币、FDV、解锁、流动性。
- 怎么复盘错误，修正仓位和预期。

## 最重要的信号

| 信号 | 重要性 | 判断方法 |
|---|---|---|
| 龙头地位 | 最高 | 是不是本生态/本叙事里最强的一两个标的？如果不是，默认只是跟涨。 |
| 催化强度 | 高 | 是否有上币、新闻、TGE、空投、生态轮动、规则变化等明确触发器？ |
| 方向性 | 高 | 事件发生后，市场方向是否容易判断？不清晰则交易价值下降。 |
| 波动性 | 高 | 是否能产生足够价格波动？只有方向没波动，利润空间有限。 |
| 流动性 | 高 | 池子、深度、税率、做市、CEX/DEX 承接是否支持进出？ |
| FDV / 流通 | 高 | 开盘估值、流通比例、初始筹码是否让散户还有利润空间？ |
| 解锁和抛压 | 高 | 项目方、VC、KOL 轮、空投用户是否有明确卖压？ |
| 持续驱动力 | 中高 | 项目方、KOL、社区、事件是否能持续推动注意力？ |
| 生态资金轮动 | 中高 | 当前资金在哪条链、哪个生态、哪个叙事里？ |

## Meme 周期框架

1. **萌芽期**：新生态、新协议、新玩法出现，讨论不多，但链上聪明钱开始试探。
2. **确认期**：龙头开始跑出，生态注意力集中，成交和社群热度同步上升。
3. **主升期**：CEX、KOL、新闻、生态资金共同放大，龙头和龙二吃主要涨幅。
4. **扩散期**：二线、三线、仿盘开始补涨，跟涨品种变多。
5. **尾部期**：非龙头普涨、FDV 抬高、项目方坐地起价、上币利润空间被压缩。
6. **退潮期**：解锁、流动性不足、叙事疲劳、明牌出货导致大幅回撤。

## 参与条件

更值得参与：

- 叙事早中期，龙头尚未完全被定价。
- 是龙头/龙二，而不是末端跟涨。
- 有明确催化，并且催化带来方向性和波动性。
- 流动性支持进出，FDV 没有完全透支。
- 有可预期退出路径，如 CEX、下一轮事件、生态扩散。

应该回避：

- 非龙头，但已经涨了几倍。
- 项目本身没有持续驱动力。
- 高 FDV、低流通、上币后利润空间被压缩。
- 空投/质押/签到规则反复修改。
- 项目方、名人或庄家明牌出货。
- 流动性不足，开盘后很快到高点。

## 空投/撸毛判断

0xSunNFT 不是“见空投就刷”，他更看：

- 是否是赛道最后一个大毛。
- 规则是否清晰、是否稳定。
- 积分或交互是否真实对应收益。
- 资金占用和时间成本是否划算。
- 是否有套保或退出方式。
- 项目是否有真实用户和后续交易需求。

## 一句话使用方法

如果你用 0xSunNFT 的知识库判断项目，先问五个问题：

1. 它是不是龙头？
2. 催化是什么？
3. 方向和波动是否足够明确？
4. 流动性、FDV、解锁是否允许你安全进出？
5. 退出路径在哪里？

五个问题里缺两项以上，就不要把它当作高质量链上机会。
