# SonMa84176 投研逻辑沉淀

## 核心定位

SonMa84176 的价值在于识别加密市场里的结构性风险：杠杆、流动性、筹码、做市、散户陷阱和上币异常。

## 最重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 杠杆清算 | 很多下跌不是基本面变化，而是杠杆出清。 | 对比 BTC、山寨、市值蒸发和强平金额。 |
| 短期持有者卖压 | 新进场资金更容易止损。 | 观察亏损、止损和链上持仓周期。 |
| 做市配置 | 项目能不能拉盘常取决于 MM 和流动性。 | 看是否有做市商、资金和流通控制力。 |
| 筹码结构 | 外部流通过大或集中度低会削弱控盘。 | 分析流通量、持币分布、团队主导权。 |
| 上币前异常钱包 | 可能暴露信息不对称。 | 关注公告前突然扫货的小钱包。 |
| 技术假突破 | 散户追涨时容易形成陷阱。 | 结合反压、楔形、成交和清算一起判断。 |

## 否决信号

| 否决信号 | 说明 |
|---|---|
| 拉盘资源不足 | 没有 MM、运营资金、流动性支持。 |
| 流通量失控 | 筹码散落在外，团队难以稳定价格。 |
| 上币前异常成交 | 可能是老鼠仓或信息优势方提前入场。 |
| 反弹只有技术诱多 | 走势像假突破，缺乏真实资金承接。 |
| 大量短期持有者亏损 | 反弹容易遇到止损和解套卖压。 |

## 使用方法

用他的体系判断项目时，先问：

1. 价格波动来自基本面，还是杠杆/清算？
2. 项目方有没有拉盘和做市资源？
3. 筹码是否集中，外部流通是否可控？
4. 公告前是否出现异常钱包？
5. 散户是否正在被诱多或集体止损？
