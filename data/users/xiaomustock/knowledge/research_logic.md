# xiaomustock 投研逻辑沉淀

## 核心定位

xiaomustock 的价值在于把公开市场交易和产业链逻辑结合起来。他更重视“长期主线 + 可交易表达”，不是纯粹项目基本面研究。

## 最重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 长期主线 | 持续主线比短期热点更能承载仓位。 | 先判断是不是 AI、存储、航天、白银、Perp 这类可持续主题。 |
| 利润池位置 | 热门赛道里也有苦生意。 | 看谁有定价权、毛利、客户绑定，而不是只看需求增长。 |
| 龙头和财富效应 | 资金会先集中到少数标的。 | 观察主线里是否出现 ASTER、AVNT 这类明确龙头。 |
| 财报和产业供需 | 二级市场最终要回到业绩验证。 | 财报暴跌但长期需求强化时，可能是低吸窗口。 |
| 交易表达降风险 | 方向对但工具错也会亏。 | 用 ETF/2x ETF 替代部分期权暴露，控制波动。 |
| 机构持仓蒸馏 | 长期股票需要边际买家持续进入。 | 跟踪明星基金和知名投资人持仓变化，做二次验证。 |

## 否决信号

| 否决信号 | 说明 |
|---|---|
| 谁都能做的生意 | 数据中心这类资本开支重、缺护城河的方向可能利润薄。 |
| 只有热度没有主线 | 两三天一换的热点难以形成持续仓位。 |
| 财富效应范围太窄 | 赚钱地址少、获利人少，难以支持大众传播。 |
| 估值已充分透支 | 即使好公司，也不能忽略市值和买点。 |
| 工具风险过高 | 期权方向正确也可能被波动、时间价值和仓位拖死。 |

## 使用方法

研究一个项目时，用他的体系先问：

1. 它属于哪条长期主线？
2. 这条主线里真正赚钱的位置在哪里？
3. 它是不是龙头，还是只是跟涨？
4. 有哪些财报、供需、机构持仓可以验证？
5. 应该用什么交易工具表达，风险是否过大？
