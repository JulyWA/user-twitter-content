# Super4DeFi 投研逻辑沉淀

## 核心定位

Super4DeFi 的核心视角是链上流动性和协议现金流。他更关心一个协议能不能真实赚钱，以及 LP 和代币持有人是否被合理补偿。

## 最重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 协议收入 | DeFi 基本面的核心。 | 看手续费收入、纯收入、持续性，而不是只看 TVL。 |
| 价值捕获 | 收入不能回到代币，代币就容易只是筹码。 | 检查回购、分红、国库和治理权。 |
| LP 风险 | LP 是系统风险的直接承担者。 | 评估无常损失、清算、项目方、合约和做市风险。 |
| 发行机制 | 初始发行决定长期激励。 | 优先看是否市场化、是否跳开过重 VC 结构。 |
| TVL 质量 | 高 TVL 不一定代表安全。 | 区分真实需求、补贴资金和短期挖矿资金。 |
| 风控标准 | 为抢 TVL 放宽标准会累积系统风险。 | 看资管机构和风险管理方是否严格。 |

## 否决信号

| 否决信号 | 说明 |
|---|---|
| 只有 TVL 没有收入 | 资金热闹不等于协议有基本面。 |
| 收入不能捕获到代币 | 用户赚钱、协议赚钱，但代币不一定赚钱。 |
| 高 APR 来源不清 | 可能只是补贴、杠杆或尾部风险价格。 |
| 风控为增长让路 | 竞争 TVL 时放宽准入，容易形成资管风险。 |
| 项目方和 LP 激励不一致 | LP 承担风险，项目方只拿增长数据。 |

## 使用方法

研究 DeFi 项目时，用他的体系先问：

1. 协议收入从哪里来，能否持续？
2. 代币怎样捕获这部分价值？
3. LP 承担了哪些风险，APR 是否足以补偿？
4. TVL 是真实需求还是补贴驱动？
5. 发行机制是否让团队和长期质量绑定？
