# BTCdayu 投研逻辑沉淀

## 核心定位

BTCdayu 的价值不在于短线交易，而在于提供一套“项目质量 + 长期趋势 + 风险过滤”的价值投资视角。

他的有效内容适合用来判断：

- 一个项目是否真的有业务和收入。
- 一个赛道是否处于长期趋势。
- 一个资产是否有护城河和利润池。
- 当前价格和估值是否已经透支未来。
- 币圈项目是否只是 PVP 和筹码游戏。

## 最重要的信号

| 信号 | 重要性 | 判断方法 |
|---|---|---|
| 真实收入 | 最高 | 有无可验证收入、利润、费用捕获，而不是只看 TVL 或交互量。 |
| 长期趋势 | 最高 | 是否处在 3-10 年级别趋势，如 AI 基建、稳定币、交易基础设施。 |
| 利润池位置 | 高 | 产业链里真正赚钱的是哪一层？项目是否处在利润池里？ |
| 护城河 | 高 | 是否有牌照、网络效应、品牌、数据、渠道、管理层等壁垒？ |
| 估值空间 | 高 | 当前估值是否已经反映未来增长？是否还有 2-3 倍以上空间？ |
| 管理层质量 | 高 | 团队是否长期主义，是否真正建设，而不是只会发币。 |
| 解锁/流通 | 高 | 好资产也可能因为解锁和小流通成为坏买点。 |
| 现金和仓位 | 高 | 坏日子不会提前通知，现金和仓位决定能否活到下一轮。 |

## 否决信号

| 否决信号 | 说明 |
|---|---|
| 无真实收入 | 纯叙事、纯补贴、纯刷数据很难长期持有。 |
| 项目方目标是卖币 | 很多 crypto 项目的默认风险是团队、VC、交易所共同找退出流动性。 |
| PVP 结构严重 | VC、项目方、交易所、KOL、散户层层互掏，普通人胜率下降。 |
| 高估值 + 小流通 | 开盘看起来热，但解禁和抛压会不断压制。 |
| 假 TVL / 假交互 | 激励刷出来的数据不能证明真实需求。 |
| 叙事衰退 | 老叙事没有新增长，只剩存量互割。 |
| 买点太热 | 好资产也可能因为情绪和筹码结构成为坏交易。 |

## 长期项目判断框架

1. **赛道**：是不是长期趋势？例如 AI 基建、稳定币、真实交易基础设施。
2. **需求**：有没有真实用户、真实收入、真实交易量。
3. **价值捕获**：项目是否能把需求转化成收入或利润。
4. **护城河**：竞争对手能否轻易复制？
5. **管理层**：团队是否长期主义，是否愿意做难而正确的事。
6. **估值**：当前价格是否合理，是否需要等解锁/回调。
7. **风险**：是否存在 PVP、VC 解锁、团队套现、假数据。

## AI 基建判断

在 AI 方向，他关注的不是“哪个应用最热”，而是基础设施瓶颈：

- 算力
- 电力
- 存储
- HBM
- 光互联
- 芯片和推理基础设施

可复用逻辑是：当 AI 需求长期增长，真正捕获利润的可能不是最前端应用，而是被需求卡住的基础设施环节。

## 稳定币 / Circle 判断

在稳定币方向，他关注：

- 是否有真实支付和结算需求。
- 发行方是否能捕获利息、手续费、平台沉淀资金。
- 是否有监管、牌照、规模和网络效应。
- 估值是否和未来收入匹配。
- 是否有 AI Agent 支付、跨境支付、链上金融等新增场景。

## Meme 判断

BTCdayu 并不完全否定 Meme，但他的门槛更偏保守：

- Meme 必须有文化和共识，而不是纯喊单。
- 要避免项目方、庄家、阴谋和 PVP 结构。
- 仓位要小，赚到幸运钱要兑现。
- 如果不能拿 6 个月，说明仓位或信念可能不对。

## 一句话使用方法

如果你用 BTCdayu 的知识库判断项目，先问七个问题：

1. 它有没有真实收入？
2. 是否处于长期趋势？
3. 是否在产业链利润池里？
4. 护城河是什么？
5. 管理层是否可信？
6. 当前估值和解锁节奏是否合理？
7. 是否存在 PVP 或项目方卖币结构？

如果收入、利润池、护城河都说不清，就不要把它当长期资产。
