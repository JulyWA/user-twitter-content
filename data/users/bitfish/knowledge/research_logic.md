# bitfish 投研逻辑沉淀

## 核心定位

bitfish 的价值不在于给出激进方向，而在于提供“风险管理优先”的底层框架。他更像一个提醒你别被市场带走的人。

## 最重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 仓位 | 普通人最可控的变量之一。 | 先定最大亏损，再谈收益。 |
| 时间尺度 | 同一个资产在不同时间尺度下风险完全不同。 | 明确是日内、波段还是长期配置。 |
| 流动性 | 流动性差会放大价格偏离和脱锚。 | 观察深度、赎回路径、稳定币兑换成本。 |
| 行为偏差 | 恐惧、贪婪、从众会制造错误价格。 | 在情绪极端时降低主观判断权重。 |
| 风险再分配 | 复杂产品常把风险从一类人转给另一类人。 | 研究 MSTR、稳定币、交易所产品时先画资金流。 |
| 可控/不可控 | 市场、宏观、他人不可控；流程和纪律可控。 | 把判断转化为流程，而不是靠情绪反应。 |

## 否决信号

| 否决信号 | 说明 |
|---|---|
| 靠预测而非流程 | 如果结论只靠猜方向，可靠性低。 |
| 仓位和时间不匹配 | 长期逻辑用短线杠杆表达，容易被波动洗掉。 |
| 流动性不足 | 小额卖压即可引发大幅波动，尤其稳定币和小盘资产。 |
| 信息不对称 | 复杂结构里散户可能承担不透明尾部风险。 |
| 情绪主导 | 睡眠不足、恐慌平仓、盯盘兴奋都会降低判断力。 |

## 使用方法

用 bitfish 的体系做研究时，先问：

1. 我能控制什么？
2. 这笔交易的最大亏损在哪里？
3. 流动性是否足够支持退出？
4. 时间尺度是否和仓位匹配？
5. 风险到底被转移给了谁？
