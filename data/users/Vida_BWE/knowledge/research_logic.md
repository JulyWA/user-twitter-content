# Vida_BWE 投研逻辑沉淀

## 核心定位

Vida_BWE 的价值在于实盘交易纪律和风险暴露管理。他更关心观点被证伪后怎么退出、仓位如何套保，以及基础设施在极端行情下是否可靠。

## 最重要的信号

| 信号 | 为什么重要 | 如何使用 |
|---|---|---|
| 观点证伪 | 交易不是证明自己正确，而是错误时少亏。 | 每笔交易提前写清退出条件。 |
| 动态止损 | 大额亏损常来自执行迟疑。 | 用趋势警报或系统化规则强制执行。 |
| 套保比例 | 账面收益不兑现就仍是风险暴露。 | 高 FDV 或高波动资产用套保锁定大部分收益。 |
| 相对估值 | 单个项目故事容易失真。 | 用 ENA、CRWV、Circle 等可比对象判断贵不贵。 |
| 基础设施可靠性 | 极端行情下系统设计决定用户损失。 | 比较 CEX/DEX Perp 的赔付、清算和责任边界。 |
| RT 信号源 | 转推能暴露他关注的交易线索。 | 使用时回溯原作者，不直接归因为 Vida 原创。 |

## 否决信号

| 否决信号 | 说明 |
|---|---|
| 被证伪还不退出 | 宏观或市场环境变化后，原 thesis 失效。 |
| 高 FDV 缺少机构承接 | 大众车、散户盘可能无人拉盘。 |
| 极端行情不赔付 | 基础设施把系统风险全部留给用户。 |
| 没有止损阈值 | 亏损超过心理阈值后执行质量会变差。 |
| 转推未追源 | 把 RT 当原创观点会污染知识库判断。 |

## 使用方法

用他的体系做交易研究时，先问：

1. 这笔交易什么时候算错？
2. 错了以后怎么退出，谁来强制执行？
3. 现在估值相对谁便宜或贵？
4. 是否需要套保，套保多少？
5. 使用的交易场所极端行情下是否可靠？
